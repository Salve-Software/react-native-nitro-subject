# Commits

- Conventional Commits, subject of 50 characters at most, imperative: `feat(ios): add saliency engine`.
- Scopes: `ios`, `android`, `detect`, `prepare`, `specs`, `types`, `example`, `release`.
- Small commits, one change each. A new function and its test are two commits (`feat`, then `test`).
- Never commit to `main`. Open a PR from `feat/*` or `fix/*`.
- Don't mention or link other projects' issues and PRs in commits, PRs or docs. GitHub adds a reference to their timeline.
